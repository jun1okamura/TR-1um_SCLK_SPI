# v64_8 — 旧 STDCELL（行高 64.8 µm）で作った**提出版**

ここに入っているのは **2025 年の MPW に提出したそのもの**。動かさない。

    src/tr_1um_3wire_SPI.gds    提出した GDS
    src/tr_1um_3wire_SPI.cir    提出した LVS ソース
    layout/                     その GDS を作った段（step1〜step10 とチップ）
    ngspice/                    そのチップに当てた TB と実行ログ

## なぜ作り直したか

正本の STDCELL は **v59_4（行高 59.4 µm）**（`TR-1um_APRtools/docs/02_stdcell_diff.md`）。
論理セルの**幅は全セル同一**だが行高が違うので、行の y もチャネルの割り付けも
別物になる。**GDS を突き合わせる形では検証できない**ので、合成からやり直して
**DRC / LVS / ngspice / STA** で判定した。新しい版は `../../layout/` と
`../../src/`。

ついでに直ったもの:

  * **U15** — コア幅 1620.0（300 トラック）は TAP の上限 1614.6（299）を
    超えていた。最終間隔 540.0 > 実測ピッチ 534.6 のまま提出されている。
    新しい版は **296 トラック = 1598.4**。
  * コア高が **1329.6 → 308.7 µm**。旧版は真ん中のチャネルを 900 µm 取った
    まま圧縮していない。APRtools の step10（squeeze）が使わなかった
    トラックを削るので、面積は 2.154 → 0.494 mm² になった。
